# **API Routes**

### GET methods

**Deck**

- Get all decks
- Get deck by ID
- Get deck by name
- Get all words in a deck

**DeckWord**

- Get all decks that contain words
- Get all reltionship id pairs in deck

**Word**

- Get all words
- Get words by ID
- Get words by name
- Get recent words by date

### POST methods

**Deck**

- Create new deck
- Create word in deck

### PUT methods

**Deck**

- Update existing deck

**Word**

- Update existing Word

### DELETE methods

**Deck**

- Delete deck
- Delete word in a deck
