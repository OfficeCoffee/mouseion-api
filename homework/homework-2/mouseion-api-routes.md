# Document for Mouseion API Routes

### GET methods
#### Word Entity
- All words
- Word by wordId
- Word where word is

#### Deck Entity
- All decks
- Deck by deckId
- Deck where deckName is

#### Deck Word Entity
- All decks containing specific word by wordId
- All words in deck 
- Specific word from specific deck by deckId and wordId

### POST methods
- New word
- New deck
- New deck_word (composite key relationship)

### PUT methods
- Update word
- Update deck
